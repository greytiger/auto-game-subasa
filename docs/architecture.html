Bước 1 • Input

Raw Screencap (ADB Socket)

Thay vì gọi adb exec-out screencap -p (nén PNG tốn 300–600ms CPU mỗi lần), tool đọc thẳng dữ liệu pixel thô.

  • Tốc độ: Nhanh hơn 5–10 lần so với nén PNG.
  • Persistent Connection: Giữ sẵn kết nối socket tới ADB server thay vì mở process mới liên tục.
  • Bộ nhớ: Giải mã trực tiếp trong RAM thành mảng NumPy để kiểm tra pixel.
raw = adb.screencap_raw() # RGBA bytes frame = np.frombuffer(raw[12:], dtype=np.uint8).reshape(H, W, 4)
